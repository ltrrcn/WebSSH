# Contract: WebSocket 终端协议

**Version**: 1 | **Branch**: `001-webssh-base-terminal`

浏览器与服务端之间唯一的终端数据通道。所有消息使用二进制帧，**首字节为帧类型**，其余字节为负载。

## 连接

- **路径**: `/ws/terminal`
- **握手校验**: 服务端必须校验 `Origin`，不匹配即拒绝（HTTP 403）
- **身份**: fnOS 模式来自 `X-Trim-Userid`；standalone 模式来自登录会话 Cookie
- **查询参数**: 只允许 `hostId`、`version`、`ticket` 与 `sessionId`（可选的一次性连接票据，经 `POST /api/ws-ticket` 签发，60 秒有效；用于网关不向 WS 升级请求注入 `X-Trim-*` 时的身份回退）。`version`（协议版本，当前为 `1`）缺失或不支持时以 HTTP 400 拒绝——对应宪法第 VIII 条「WS 握手参数必须携带 version 字段」。`hostId` 必须为已保存且归属当前用户的主机。**不接受** `host` / `port` / 凭据等参数
- **关闭码**: `4001` 未授权、`4003` 主机不在授权范围、`4004` 并发上限、`4005` 指纹未确认、`4006` 连接失败、`4007` 会话不可接管（不存在 / 不属本人 / 非挂起态）、`4010` 空闲超时、`4011` 执行超时、`1000` 正常关闭
- **断线保活与接管（FR-059）**: 携带 `sessionId` 的握手用于接管**已挂起**的会话，服务端校验该会话归属当前用户；接管不占用新的并发名额，也不再校验主机与指纹。未携带 `sessionId` 即新建会话
- 客户端以 `1000` 主动关闭 → 服务端立即释放 SSH；其余断开（刷新/关窗口 `1001`、网络异常 `1006`）→ 会话转为 `detached` 挂起保活，SSH 连接与远端进程保持，等待接管；超过 `limits.detachedTtlMs`（默认 10 分钟）未被接管则回收

## 帧类型

| 首字节 | 方向 | 含义 | 负载 |
|---|---|---|---|
| `0x00` | 双向 | 终端数据（原始字节流） | 原始字节，原样转发 |
| `0x01` | C→S | 窗口尺寸变更 | UTF-8 JSON：`{"cols":<number>,"rows":<number>}` |
| `0x02` | C→S | 信号 | UTF-8 JSON：`{"signal":"INT"}` |
| `0x03` | S→C | 会话元信息 | UTF-8 JSON：`{"sessionId":"s_ab12"}`，连接就绪后下发一次 |

约束：

- `0x03` 仅由服务端发出，客户端在无法识别时**必须忽略**该帧（向后兼容）；客户端据此把本地会话卡与审计记录中的「会话 ID」对应（后台运行/已断开的会话可在审计中定位并继续连接）
- `sessionId` 命名：`S` + 连接时刻的年月日时分秒 `YYYYMMDDHHmmss`（如 2026-10-13 15:30:45 → `S20261013153045`）；同一秒内的后续会话追加序号 `-2`、`-3`… 以保证进程内唯一

- `0x00` 负载不得被解析为文本，必须原样透传（保证控制字符与多字节字符完整）
- `cols` / `rows` 必须为 1–1000 的整数，非法值丢弃并计入审计
- `signal` 仅允许白名单内的值（初始仅 `INT`）

## 时序

1. 客户端发起握手并通过校验
2. 服务端建立 SSH 连接；主机指纹未确认时发送关闭码 `4005` 并在 HTTP 层提供确认接口
3. 连接就绪后服务端先下发 `0x03` 会话元信息（含服务端会话 ID），随后进入双向转发：客户端 `0x00` → SSH stdin；SSH stdout → 客户端 `0x00`
4. 客户端以 `1000` 关闭、空闲超时 → 服务端释放 SSH 连接并以对应关闭码结束；网络断开/刷新 → 会话挂起保活（`detached`），重新握手携带 `sessionId` 即可接管，接管时服务端回放挂起期间的输出并重发会话元信息

## 错误语义

- 认证失败：关闭码 `4006`，错误信息不得包含凭据
- 主机不可达或超时：关闭码 `4006`
- 输出体量过大：不限制转发，但客户端须保持可响应（由前端渲染层控制）
