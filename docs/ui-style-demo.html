W WebSSH STYLE DEMO

01 · 色彩令牌

三级文字层级 text → text-dim → text-faint；语义色永远成对使用（实色 + soft 底）。切换右上角主题可验证双主题表现。

02 · 按钮

按下统一 scale(.97)；primary hover 为 brightness 提亮 + accent-soft 投影。

03 · 徽章

默认 在线 连接中 失败 置顶 已结束

04 · 表单（聚焦扫描线）

聚焦 = 双层光晕（内环 3px + 外圈 20px accent-soft）+ 底部扫描线从左向右铺满；光标颜色跟随主题色。

05 · 开关 · 分段选择器 · 滑条

断线自动重连 记住口令
13px

06 · 树形分组列表（侧栏范式）

折叠动画用 grid-template-rows: 1fr → 0fr（不依赖 max-height）；连接行左缘 3px 绿色竖条高度 0 → 60% 展开。
